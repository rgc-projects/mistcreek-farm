# 雾溪农场 · Mistcreek Farm

原创像素农场游戏。春夏秋冬每季 14 个游戏日，每年 56 天。季节改变作物供应、村民日常、户外环境和天气；萝卜与豆子全年能种。不能越季的未成熟作物会退回种子，成熟作物依然可收。

- **养殖**：在农舍西边建畜棚，可饲养河鸭和云绒羊。喂食后过夜收取产物，可出货，也可去雾溪镇加工。漏喂只会暂停产出。
- **农场升级**：食槽处可扩建畜棚，在雾溪镇加工坊可强化水壶，批量浇水从三格增到五格。
- **电脑操作**：「玩法」可选择点地图或经典键鼠。经典模式下 WASD 移动，左键/C 用工具，右键/X 互动，E 打开背包，滚轮切换工具；触屏仍点地图。
- **探索**：M 打开地图，农事历查看天气和换季。季节、旧水灯任务、加工、送礼、渡船与芦苇浅滩保留。
- **存档**：进度存在当前浏览器，支持导入、导出和备份恢复；v1–v4 的原始存档保留，新版自动迁移。

本地运行：`python3 -m http.server 8000 --directory dist`  
测试：`node --test tests/*.test.cjs`

目前尚未完成全年主线结局、更长的村民故事和节庆。

## 部署到 Cloudflare Workers

在 Workers & Pages 中选择连接 Git 仓库，并选中 `rgc-projects/mistcreek-farm`。项目名保持 `mistcreek-farm`，生产分支选 `main`，根目录保持仓库根目录（`/`），构建命令留空，部署命令用 `npx wrangler deploy`。

`wrangler.jsonc` 会把 `dist/` 作为静态站点发布。不需要 Worker 脚本、构建步骤、环境变量或额外绑定。如需免登录访问，请保持 Cloudflare Access 关闭。

新域名不会自动继承旧域名上的浏览器存档。请在旧站打开「存档」导出，再到新站导入。
